# Security Policy

Please don't report security issues in public issues or Slack. Use [private reporting on the Kepler repository](https://github.com/sustainable-computing-io/kepler/security/advisories/new) instead. Mention kepler-operator, the version and how to reproduce it.

This repository follows the [Kepler security policy](https://github.com/sustainable-computing-io/kepler/blob/main/SECURITY.md).
